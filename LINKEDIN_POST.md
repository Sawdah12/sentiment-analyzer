🚀 Just built my first full-stack AI project in 3 days!

**Sentiment Analyzer** — a web app that tells you if your text is positive or negative using NLP.

🔧 Tech Stack:
• HuggingFace Transformers (DistilBERT)
• Flask REST API (Python)
• React + Vite frontend

📌 What it does:
→ Accepts any text input
→ Runs it through a pre-trained DistilBERT model
→ Returns POSITIVE/NEGATIVE with a confidence score

💡 What I learned:
✅ Loading pre-trained NLP models from HuggingFace
✅ Building REST APIs with Flask
✅ Connecting a React frontend to a Python backend
✅ Handling model loading, CORS, and async API calls

The model runs locally — no API keys, no cost, just pure transformers! 🤗
